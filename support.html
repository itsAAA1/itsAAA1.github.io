الدعم الفني والإبلاغ عن المخاطر

هذه الصفحة توضح قناة تواصل قابلة للتتبع، وطرق التأكد من الروابط، وما يحدث عند اكتشاف مشكلة في موقع VoltZilla.

قناة الدعم المفتوحة

تُسجل ملاحظات الموقع أو أخطاء الروابط أو تقارير التصيد عن طريق فتح Issue في مستودع VoltZilla. هذا المسار يتطلب حساب GitHub ويمكن الاطلاع عليه علنًا؛ **لا تنشر فيه معلومات شخصية أو محافظ سرية أو بيانات استرداد**.

للمتابعة العامة حساب X المصرّح به @voltzillasol1؛ لاحظ أن بيانات العقد تذكر ملف X آخر، والعلاقة بينهما غير متحققة حتى الآن. البريد الرسمي المخصص للدعم لم يُعتمد، لذلك لا ننشر عنوانًا مختلقًا.

كيف نتحقق من رسالة أو طلب توقيع؟

  • طابق العقد كاملًا مع العنوان الظاهر في صفحة التحقق ومعاملة الإنشاء على Solana.
  • لا تشارك عبارة الاسترداد أو المفتاح الخاص مع أي موقع أو خدمة دعم، بما في ذلك نموذج الإدراج.
  • إثبات التحكم بمحفظة يكون بتوقيع رسالة واضحة غير مالية بعد فهم نصها، وليس بتحويل SOL أو الموافقة على معاملة شراء.
  • لا تستخدم روابط تردك برسائل خاصة تزعم أن الإدراج مضمون مقابل الدفع.

الاستجابة للحوادث

في حال وجود رابط مشبوه أو صفحة تزعم أنها المشروع، تُحفظ الأدلة العامة مثل الرابط والتاريخ والعقد وتُنشأ تذكرة GitHub. يتم فحصها ومقارنتها بمصادر السلسلة، ثم تحديث صفحة الحالة إذا ثبت التغيير. التوكن نفسه لا يمكن إيقاف تداوله من خلال GitHub Pages، ولا تملك هذه الصفحة سلطة لحماية أرصدة المحافظ.

الخصوصية والبيانات

الموقع الحالي صفحات ثابتة لا تطلب محفظة أو تسجيلًا ولا يجمع بيانات مالية عبر نموذج محلي. قد يجمع مضيف الموقع GitHub وموفرو الروابط الخارجية بيانات تقنية وفق سياساتهم الخاصة؛ الانتقال لأي منصة خارجية يخضع لسياساتها. المراسلات العامة في GitHub Issues ظاهرة للزوار.
